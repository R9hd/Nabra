## NABRA: seizure alert app (demo build)

The collar is **simulated** in this build: use *Monitor → Simulate seizure (demo)* to trigger an alert.

### Install on Android
1. On your Android phone, download **NABRA.apk** below.
2. Open it. If asked, allow *Install unknown apps* for your browser or Files app.
3. Open NABRA and allow notifications, location and phone calls when asked.

### iPhone, or no Android phone
Use the web version (same accounts, same data): **https://r9hd.github.io/Nabra/**
Lock-screen alerts, the alarm sound in the background and automatic calls only work in the Android app.

### Try the full flow (two devices)
1. **Device 1:** sign up as **Patient** → *Pair* → note the 5-letter pairing code.
2. **Device 2** (a second phone, or the web link on a laptop): sign up as **Caregiver** → enter the code.
3. **Device 1:** *Monitor → Simulate seizure (demo)* → wait 10 s (or tap *Send now*).
4. **Device 2** gets the emergency alert → tap *I'm responding* → *Seizure ended*.
5. Check *History*, *Event detail* and *Statistics* on both devices.

Do not test the emergency call with 997. To test the 5-minute automatic call, set a friend's number in *Settings → Emergency auto-call*.

NABRA is a hackathon prototype, not a certified medical device.
